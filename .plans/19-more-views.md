# Column view

Depends on shared selection and Quick Look. This optional presentation milestone does not block remote browsing, worktrees or agent handoff.

- Column view (⌥⌘3): Miller columns with keyboard navigation that matches what → and ← already do in the list.
- Grid ⌥⌘2 stays as Finder's Icons equivalent. ⌘1 to ⌘0 open favorites.
- It reads the shared selection model from [selection](02-selection.md).
