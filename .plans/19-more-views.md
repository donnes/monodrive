# Column and gallery views

Depends on shared selection and Quick Look. This optional presentation milestone does not block remote browsing, worktrees or agent handoff.

- Column view (⌘3): Miller columns with keyboard navigation that matches what → and ← already do in the list.
- Gallery view (⌘4): a large preview of the selection with a strip of thumbnails. It reuses the thumbnail pipeline and Quick Look for other types.
- Grid ⌘2 stays as Finder's Icons equivalent.
- Each view reads the shared selection model from [selection](02-selection.md).
